# OIBSIP — Data Science Internship Projects

This repository contains projects developed as part of the Oasis Infobyte Internship (OIBSIP).

## Project

### Task 4 — SpamGuard AI: Email Spam Detection

A machine-learning web application that classifies messages as spam or legitimate using TF-IDF, Multinomial Naive Bayes, and Logistic Regression.

- **Live application:** https://spamguard-ai-two.vercel.app/
- **Backend API:** https://spamguardai-api.onrender.com/
- **API documentation:** https://spamguardai-api.onrender.com/docs
- **Project source and instructions:** [DataScience-Task4-EmailSpamDetection](./DataScience-Task4-EmailSpamDetection/)

## Technologies

Python, scikit-learn, NLTK, FastAPI, React, TypeScript, Vite, and Tailwind CSS.

## About

These projects demonstrate practical data science and machine-learning skills through hands-on development and deployment.
